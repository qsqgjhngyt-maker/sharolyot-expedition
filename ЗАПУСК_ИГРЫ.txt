ШАРОЛЁТ — ДАЛЬШЕ ЗВЁЗД · 0.3

1. Распакуйте архив целиком.
2. Нужен установленный Node.js 24: https://nodejs.org/.
3. Дважды щёлкните START_GAME.cmd. Браузер откроется сам.
4. Оставьте окно запуска открытым. Ctrl+C останавливает игру.

Готовая сборка dist включена. Для игры не нужен npm install.
Не запускайте dist/index.html двойным щелчком — нужен локальный HTTP-адрес.

J / Tab — девять миссий, прогресс, награды и повторное прохождение.
C — связь с участником текущего задания.
F — корабль / интерьер / возврат на борт.
G — поверхность после посадки.
V — выход в открытый космос в скафандре, после взлёта.
B — аварийное спасение из скафандра.
WASD — движение / полёт / ранец. Shift — ускорение.
Space / Ctrl — вверх / вниз. X — тормоз.
R — курс на цель; в скафандре поворачивает камеру к кораблю.
L — посадка / взлёт. E — действие; удерживать для сканирования.
ПКМ + мышь — камера. Колесо — расстояние камеры.
M — атлас / экипаж. H — помощь. Esc — пауза.

Для первой миссии: примите задание Пина по C. F — внутрь, научный
терминал слева в рубке, E. Затем летите к Лазурной. Ближе 42 ед. до
поверхности тормозите X и садитесь L. G — на площадку, E у объекта.
Вернитесь F, вызовите Лосяша по C и завершите задание.

Пройденные миссии можно переигрывать, сохраняя лучшие результаты.
Незаконченные миссии можно отложить и продолжить с контрольной точки.
Прогресс хранится в браузере, отдельно для каждого адреса / порта.

Музыка и эффекты работают локально. Диалоги синтезируются русским голосом
Windows / браузера при его наличии. Это не оригинальные голоса актёров.
Звук, музыка и речь включаются отдельными кнопками.

README.md — полное описание. ROADMAP.md — дальнейшие этапы.
NOTICE.txt — происхождение моделей, референсы и сведения о правах.
Это неофициальный фан-прототип с собственными упрощёнными моделями.

ТЕЛЕФОНЫ И ПЛАНШЕТЫ / ВЕРСИЯ 0.3
Откройте опубликованную HTTPS-страницу игры. Доступны левый стик движения,
правый стик камеры и кнопка ⋯ со всеми действиями. Пауза — настройки,
установка приложения, экспорт и импорт прогресса. Android: «Установить
игру» или пункт установки в браузере. iPhone / iPad: Safari → Поделиться
→ На экран Домой. Подробности в MOBILE_PWA.md.
После первой полной загрузки ресурсы сохраняются для запуска без сети.
Это локальное сохранение, без облачной синхронизации между устройствами.
